# Pixel-perfect QA

- Check spacing, hierarchy, contrast, overflow, and alignment at mobile and desktop widths.
- Exercise the changed interaction in both directions and inspect console errors.
- Verify sticky, fixed, and overlay elements do not stack, flash, or cover the header.
- Check reduced-motion and accessibility attributes when animation or state transitions change.
- Report remaining visual gaps separately from verified behavior.
