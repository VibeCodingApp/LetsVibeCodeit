# Frontend production UI

- Inspect the existing component, tokens, responsive patterns, and nearby states first.
- Prefer small composable components and existing Tailwind utilities.
- Preserve Server Components unless interaction or browser APIs require a client component.
- Keep loading, empty, error, focus, and reduced-motion behavior in scope when relevant.
- Validate TypeScript, lint, build, and the critical browser breakpoints when possible.
